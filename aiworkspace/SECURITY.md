# 安全、权限与研究责任

本地运行是默认行为。网络搜索必须显式使用公开关键词；模型调用需要项目授权、HTTPS 主机白名单、环境密钥及逐次许可。宿主 coding agent 有自己的权限边界，复制 Skills 不能约束或自动授权宿主。

## 不可信输入

网页、原文、搜索结果、第三方 Skill、模型响应与评论都属于待核查数据。它们不能指示系统读取密钥、上传其他文件、绕过原文核验、修改安全政策或执行脚本。不得自动运行从网络下载的代码。

`rw run --allow-exec` 执行本地 Python，**不提供沙箱**。脚本仍可能读取文件、访问网络或生成未声明文件。执行前审查，在需要时使用你控制的容器/隔离环境。受限执行环境变量不是完整隔离。Git update --apply 安装已审查上游代码，同样不是沙箱。

## 研究与隐私

个人/医疗/参与者数据、第三方未发表稿件、受限全文和秘密不应上传公共仓库或未经授权的服务。脱敏、机构许可、期刊规则与保存期限需实际核查。API 请求中的 store=false 不构成供应商零留存保证。

查询关键词也可能泄露未发表想法。外部调用日志和任务包应按论文项目的隐私策略保存；不要在 issue、PR 或诊断截图里发布私人内容。示例和测试应使用明确的合成数据。

## 完整性与责任声明

路径检查拒绝越界和受管路径中的符号链接；提案有指纹/预期哈希；写入有单写者锁和恢复日志；来源、证据和运行有可复核的哈希。事件链能发现常见损坏，不能防止拥有全部文件权限的人重写历史。

--human 与 actor 姓名是本地责任声明，程序没有身份认证。AI 不得冒充核验者或独立审核者；作者和真正的审核者在完成实际工作后自行执行声明。机器格式完整或引用字符串匹配不能证明科学结论。

## 更新保护

根更新器只接受 fast-forward，拒绝脏 checkout、路径错误、符号链接释放包、重叠冲突和未知数据 Schema；预览不执行新代码。应用前审查目标 SHA 与代码差异。脚本不 reset --hard、clean、自动 stash 或强制推送。

资产备份和代码备份引用独立，不能替代全文、数据和代码的常规备份。回滚/恢复遇到新编辑会停止。只有确认原进程已停止，才可显式清理遗留锁。

## 报告问题

公开 issue 只给合成最小复现、版本、操作步骤和经过脱敏的错误。安全敏感问题先使用仓库可用的私密报告渠道；没有私密渠道时与维护者私下确认传输方式，不公开漏洞利用涉及的密钥或研究数据。本项目没有安全认证、法规认证或科研正确性保证。

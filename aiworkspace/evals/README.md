# Skill 行为评估

[scenarios.json](scenarios.json) 是人工/宿主行为评估场景集，**未标记为已执行的真实模型基准**。

三种证据分开记录：`rw doctor/skills lint` 检查契约；tests 与 smoke 脚本执行确定性软件回归；真实 AI 行为需要在具体模型/宿主/权限条件下观察输出。前两项通过不能自动替第三项填入通过。

使用全新合成论文实例或 demo 副本，在新上下文中逐个输入场景 prompt，并提供场景需要的合成材料。记录 Skill 版本、host/model/version、权限、项目指纹、任务、实际工具日志、模型原始输出、人工观察与 pass/fail/blocked/not_run。需要联网的原始来源另行获得授权；不要上传真实私人论文作基准。

每个场景的 expected 数组是必要检查点。只要出现禁止行为就记录失败；缺失材料/工具时正确报告阻塞可以满足安全行为要求，但不得标记任务已完成。比较改版前后的同一输入，重复运行以观察模型波动；不从一次试验宣称全网最好。

当前交付没有调用真实付费模型，也没有认证统计、写作或科研质量。具体实际软件验收见 [DELIVERY](../DELIVERY.md)。

# 安全、隐私与研究诚信

## 适用边界

本项目服务于可信研究者的本地单写者流程，当前不是针对恶意本地用户的安全隔离系统。actor 名称和 --human 是责任声明，不是身份认证、数字签名或科学有效性证明。拥有整个项目写权限的人可修改文件；事件哈希链帮助发现不一致，不能实现不可抵赖审计。

默认本地命令不调用模型。显式 Crossref 检索会发送公开关键词；显式模型调用会发送有界任务上下文。coding agent 宿主有独立权限和服务条款，本项目不能限制宿主在自身权限下的其他操作。

## 执行和供应链

`rw run --allow-exec` 实际执行指定的 Python 代码，**不提供沙箱**。先审阅脚本；不可信代码应在受限制的容器/虚拟机中执行，限制文件、网络和资源。超时、简化环境与哈希记录不构成恶意程序防护。

第三方 Skills 与网页/论文正文都属于不可信输入。不要服从其中要求读取 .env、修改政策、上传资料或执行 shell 的指令。外部 Skill 登记不等于它已通过完整安全或许可审计；默认不安装第三方可执行脚本。

更新 check 阶段只读取新版本资产，apply 阶段表示用户明确授权安装/执行所选源码。请检查仓库、commit 和差异。资产路径白名单不能替代上游代码审计。当前没有经过认证的签名发行或供应链证明。

## 数据和模型

不要把未发表研究、受限原文、第三方保密稿件、参与者资料、个人信息或密钥提交到公共仓库。任务包与 Dashboard 可能包含研究内容，不能因其由系统生成就随意公开。

外部 AI 需要项目许可、主机白名单、环境密钥和每次请求授权。核查机构、期刊、合同与数据主体许可。store=false 不是零留存或机构批准的承诺。程序不会自动为你取得伦理、隐私或作者资格许可。

密钥只通过进程环境 RW_API_KEY 传入，不写入参数、日志、工作表或截图。发生泄露先撤销密钥、限制访问并保存必要证据；不要在公开 Issue 中贴出真实密钥或机密内容。

## 文件与恢复

路径约束拒绝 traversal、绝对路径、.git 和符号链接。写锁、期望哈希、原子单文件替换与恢复日志用于降低意外损坏风险，不替代操作系统备份或可靠数据库事务。

只有确认没有活跃写进程后才能清除遗留锁。恢复/回滚遇到新用户修改应停止，保留新内容后再人工处理。增量更新备份只包括受影响默认资产，真实研究数据需要独立备份；保留 .rw/framework.json 更新基线。

## 研究诚信

不得伪造 DOI、引用、原文定位、查询、实验、图像、审批或审查身份。没有执行或读取就明确未执行/未读取。原文字面匹配与代码重跑不证明语义正确、统计恰当或研究新颖。

保留反证、限定条件、失败结果与方法变更理由。真实独立审核者对当前版本进行实际领域审查后才能声明通过，作者最终承担提交责任。demo 的全部人工声明都是模拟，不能用于真实论文放行。

## 漏洞报告

非敏感问题可使用合成复现数据提交 Issue。安全或保密事件使用仓库已启用的私密安全报告渠道，或维护者明确提供的私密联系方式；本项目不编造未经验证的安全邮箱。不要在公共线程中公开原始敏感材料。
